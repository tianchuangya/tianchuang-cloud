# 天创云端功能路线与未完成清单

本文档是项目内的长期实施依据。状态只能在代码和验证完成后更新，不能因为已有参考组件就标记为完成。

## 状态定义

- `完成`：已接入真实数据或真实交互，完成测试和视觉检查。
- `部分完成`：核心入口存在，但参考组件的完整能力或后端流程尚未完成。
- `待实现`：仅保留需求和原始参考代码，产品中尚不可用。

## 实施规则

1. 不把参考组件原样堆进产品；先确定用户任务、数据来源、空状态和退出路径。
2. 不展示未连接后端的假按钮。尚未实现的功能保留在本清单，不进入正式界面。
3. 每个 GPU 效果必须按需加载，并验证桌面窗口、低分辨率、减少动态效果和销毁后的 WebGL 上下文。
4. 每组成熟功能完成后运行 `npm run lint`、`npm test`、`npm run build`，视觉检查后再提交推送。
5. 除非用户明确要求，不生成安装包。
