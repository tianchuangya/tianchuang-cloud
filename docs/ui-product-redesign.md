# 天创云端正式产品 UI 改造规范

## 1. 目标

当前界面的动画质量已达到内测要求，但背景、玻璃、发光强调与卡片同时争夺注意力，信息层级偏弱。本轮改造把天创云端从“视觉展示型界面”收敛为长期使用的桌面生产力工具：稳定、清楚、可信，同时保留少量具有辨识度的动态反馈。

## 2. 视觉令牌

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 云夜 | `#0D1117` | 窗口基础背景 |
| 岩板 | `#151C25` | 内容表面与卡片 |
| 分界 | `#2A3442` | 描边和分隔线 |
| 雾白 | `#F2F5F8` | 主文字 |
| 冷灰 | `#A5B0BE` | 次要文字 |
| 云蓝 | `#6C9CFF` | 主操作、选中和同步轨迹 |

成功、警告和危险分别使用 `#4FC38A`、`#E0A84E`、`#F06B72`，不得作为装饰色。

## 3. 字体与密度

- 中文使用 `Segoe UI Variable`、`PingFang SC`、`Microsoft YaHei` 的系统回退链。
- 页面标题 28px，模块标题 15px，正文 12px，辅助信息不得低于 10px。
- 路径、目标地址和状态信息优先保证可读性，不再使用 8px 正文。
- 主要内容左对齐；只有空状态和启动画面允许居中。

## 4. 页面结构

```text
┌─ 产品栏：品牌 / 当前状态 ──────────────────────────────┐
├─ 导航栏 232px ─┬─ 页面标题 / 主要操作 ─────────────────┤
│ 资料库          │                                      │
│ 资料库列表      │  状态摘要                             │
│                 │  资料库卡片 / 文件 / 同步目标         │
│ 活动记录        │                                      │
│ 设置            │                                      │
└─────────────────┴──────────────────────────────────────┘
```

- 导航栏使用稳定实体表面，与内容区通过单条分隔线区分。
- 默认资料库视图采用原创“资料库星轨”：左侧编号节点控制焦点，主区域只展示当前资料库的同步拓扑与关键操作，避免重复卡片墙。
- 总览页单击左侧节点只聚焦，双击或点击“进入资料库”才进入；资料库详情页单击节点直接切换。
- 内容卡片以边框和层级组织，不给每张卡片叠加独立大阴影。
- 动态网格、手风琴和深度轮播保留为用户可选视图，不作为正式默认视觉依据。

## 5. 动效原则

- 保留页面切换、同步进度、冲突确认和操作结果动效。
- 悬停只改变表面、边框或 1–2px 位移，不叠加发光、缩放与背景光晕。
- 背景动画默认弱化；减少动态效果时完全停用非必要动画。
- 动效必须解释状态变化，不用于填补空白。

## 6. 自检与取舍

初稿曾考虑继续强化玻璃与渐变，也尝试了更精致的规则卡片，但它们都没有解决左侧资料库列表重复、像文件管理器的问题。最终把辨识度集中在“编号节点轨道 + 当前资料库拓扑环”：借鉴虚拟空间界面的聚焦感，不复刻任何影视作品的具体菜单、图标或布局。用户自定义背景仍然保留，但它不再决定文字和操作的可读性。
