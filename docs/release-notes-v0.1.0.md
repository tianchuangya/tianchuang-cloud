# 天创云端 0.1.0

首个公开预览版本，提供跨平台、多目标的资料同步基础能力。

## 核心能力

- GitHub、Gitee、通用 Git、WebDAV、本地磁盘、移动硬盘和已挂载网络磁盘同步
- 同一资料库配置多个备份目标
- 文件变化与应用聚焦时自动检查，也可完全关闭自动同步
- GitHub 登录、自动创建仓库、邀请只读或可更新协作者
- 远端更新、本地独有文件、超大文件、分支分叉和删除传播确认
- 自定义资料库封面、背景图片、动态背景效果和玻璃界面

## 发布说明

- Windows：NSIS 安装程序，x64
- macOS：DMG，Intel x64 与 Apple Silicon arm64
- Linux：AppImage 与 DEB，x64
- 本版本尚未进行商业代码签名与 Apple 公证，系统可能显示来源安全提示
