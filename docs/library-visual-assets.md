# 资料库视觉资源分类

来源：项目根目录 `图/`。本轮按实际像素尺寸递归检查了 250 张图片，并按宽高比分组：

- 缩略图：`0.80 ≤ 宽/高 ≤ 1.25`，203 张（去重后 157 张）。适合左侧圆形资料库节点。
- 背景图：`宽/高 ≥ 1.40`，20 张。适合资料库概览的横向聚焦舞台。
- 暂不自动使用：27 张（去重后 25 张），主要是竖图和 1.25–1.40 的临界比例图片。竖图强行铺满宽屏会丢失大量主体。

当前从上述候选中内置了 10 张方形图和 10 张横图：

- `public/assets/library-defaults/thumbnail-01.jpg` 至 `thumbnail-10.jpg`。
- `public/assets/library-defaults/background-01.jpg` 至 `background-10.jpg`。

资料库 ID 在创建时随机产生且保持稳定，界面会用它从两个资源池分别选取图片。因此每次导入看起来是随机分配，重启后又不会无故换图；用户设置的自定义图片优先级更高。

用户设置的缩略图和背景分别保存在资料库根目录的 `.tianchuang-cover.*` 与 `.tianchuang-background.*`。两个文件互不覆盖，并会随资料库同步。
